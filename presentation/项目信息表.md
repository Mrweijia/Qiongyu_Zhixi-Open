## 〇、项目说明（报名表正文，总字符 943 / 上限 1000）

> 本节按报名表要求撰写，覆盖：项目背景、现实痛点、核心方案、创新点、技术与实施可行性、绿色价值、社会影响、商业/推广潜力、团队优势。可直接复制进报名系统。

【项目背景】空气质量直接关系公众健康与城市治理。PM2.5、臭氧等污染的健康危害已被广泛证实，而站点级、逐小时的污染预测长期依赖数值模拟或人工经验，成本高、更新慢，难以支撑学校、园区等一线场景的即时决策。

【现实痛点】一是时空耦合建模难，十个监测站随风场相互影响，单站建模丢失空间信息；二是数据质量差，停报站缺失近九成，时区错位、异常值混入普遍；三是常见评测存在信息泄露，论文分数虚高、上线即失效；四是模型难以下沉，成果停留在代码里，普通用户用不上。

【核心方案】我们构建"数据清洗—模型研发—在线预测—结果解释—多端部署"的完整链路：以长沙十站过去12小时污染与气象观测为输入，一次前向直接输出未来1至3小时四种污染物共120个预测格，逐格附版本化风险提示；同一模型包以网站版、软件版、API/SDK三种形态服务不同用户。

【创新点】一是双主线模型：工程特征LightGBM与PM2.5残差Huber，四折历史滚动回测宏R²达0.886、0.804、0.740，12个组合全部逐折稳定胜出；二是无泄露评测协议：三段切分零交集、标准化仅训练段拟合、bootstrap显著性检验与实验收据制度；三是版本化风险阈值随每格结果输出，可审计、可复核。

【技术与实施可行性】部署模型仅11.2万参数，CPU即可推理，一台小服务器可稳定服务；数据清洗约0.03秒、端到端预测0.5秒级；170项自动化测试与容量验收通过，数据、模型、流水线哈希闭环，干净环境可复现。

【绿色价值】轻量模型带来低碳算力占用；提前1至3小时的预测支持"明早暂停操场活动"等可核实的预防性行动；秒级确定性清洗替代小时级人工整理。

【社会影响】为学校、园区、社区提供低成本、可解释的空气质量参考，辅助敏感人群场景的预防性安排（成效待真实试用验证）；材料全链路披露边界，倡导可复核的科研范式。

【商业与推广潜力】三形态覆盖普通用户、机构与集成方；先以长沙学校、园区试点打磨体验，再按站点契约与字段映射扩展至其他城市；开源代码与公开脱敏数据集可加速生态共建。

【团队优势】团队具备数据工程、时序建模、后端与全栈交付的完整能力，已独立完成从数据到产品的全链路闭环；以预注册晋级门槛、对抗性自检与诚实边界清单保障科研诚信。[待补充：成员背景与分工]

## 二、问题与方案

| 条目 | 内容 |
|---|---|
| 解决的问题 | ① 站点级逐小时污染预测的时空耦合建模难；② 监测数据缺失/停报/时区错位严重；③ 常见评测存在信息泄露、分数虚高；④ 模型成果难以下沉为普通用户可用的工具 |
| 目标用户 | 学校/园区/社区管理者（网站版）；有数据边界要求的机构（本地软件版）；集成开发者（API/SDK/CLI） |
| 输入契约 | 10 站 × 过去 12 小时 × 六种污染物（PM2.5、PM10、SO2、NO2、O3、CO）+ 四类气象特征 |
| 输出规模 | 一次预测 = 10 站 × 4 污染物 × 3 时段（T+1/T+2/T+3）= 120 个预测格，逐格附风险等级 |
| 产品形态 | 网站版（Web 工作台）· 软件版（本地工作台，同一套代码与模型包）· 开发者版（Flask API + Python SDK + CLI 共 10 条命令） |
| 数据接入 | CSV/JSON 文件导入、REST 推送、HTTP 定时拉取、MQTT 回调 → 统一标准事件 → 幂等去重 → 72 小时滚动窗口 |

| 条目 | 内容 |
|---|---|
| 部署模型 | `multistep_v2`（时空图神经网络，112,848 参数，CPU 可推理） |
| 模型标识 | 模型哈希 `818017da87b7` · 流水线 `2026-09-03-scientific-audit-v1` |
| 训练/验证窗 | 训练 2022-01-01→2025-02-16；验证至 2025-08-22（scaler 仅训练段拟合） |
| 验证集指标（口径：validation） | 联合 R²：T+1 **0.947** / T+2 **0.872** / T+3 **0.801**；PM2.5 MAE：3.58 / 5.09 / 6.12 μg/m³ |
| 主结论模型 1（口径：四折历史回测） | Engineered LightGBM 宏污染物 R²：**0.886 / 0.804 / 0.740**；MAE 4.66 / 7.02 / 8.62 |
| 主结论模型 2（口径：四折历史回测） | PM2.5 Residual Huber MAE：**3.77 / 6.06 / 7.76** μg/m³；相对 Persistence skill +6.6% / +7.4% / +8.4% |
| 增益显著性 | 12/12 个"污染物×步长"组合 4/4 折 MAE 与 R² 双指标优于 Plain；48 个逐折 MAE bootstrap 区间全部不跨 0；9 站消融同结论 |
| Baseline 体系 | Persistence、Climatology、LightGBM、GRU/LSTM、CNN-LSTM、Transformer、完整 T-GCN/MoE |
| 创新方向（已实现） | Wind-Gated TCN、Adaptive Graph Transformer、PM2.5 残差 Huber、Causal GAT（Granger 有向预测图）、DDPM 概率预测、时空 Foundation 等 |
| 科研纪律 | 实验收据制度（配置/seed/commit/数据哈希/时间范围/指标/checkpoint 哈希缺一不可）；预注册晋级门槛（宏R²≥0.003 或 MAE≥1%）；停止规则防过拟合调参 |
