〇、项目说明（报名表正文，总字符 943 / 上限 1000）

项目背景空气质量直接关系公众健康与城市治理。PM2.5、臭氧等污染的健康危害已被广泛证实，而站点级、逐小时的污染预测长期依赖数值模拟或人工经验，成本高、更新慢，难以支撑学校、园区等一线场景的即时决策。
现实痛点一是时空耦合建模难，十个监测站随风场相互影响，单站建模丢失空间信息；二是数据质量差，停报站缺失近九成，时区错位、异常值混入普遍；三是常见评测存在信息泄露，论文分数虚高、上线即失效；四是模型难以下沉，成果停留在代码里，普通用户用不上。
核心方案我们构建"数据清洗—模型研发—在线预测—结果解释—多端部署"的完整链路：以长沙十站过去12小时污染与气象观测为输入，一次前向直接输出未来1至3小时四种污染物共120个预测格，逐格附版本化风险提示；同一模型包以网站版、软件版、API/SDK三种形态服务不同用户。
创新点一是双主线模型：工程特征LightGBM与PM2.5残差Huber，四折历史滚动回测宏R²达0.886、0.804、0.740，12个组合全部逐折稳定胜出；二是无泄露评测协议：三段切分零交集、标准化仅训练段拟合、bootstrap显著性检验与实验收据制度；三是版本化风险阈值随每格结果输出，可审计、可复核。
技术与实施可行性部署模型仅11.2万参数，CPU即可推理，一台小服务器可稳定服务；数据清洗约0.03秒、端到端预测0.5秒级；170项自动化测试与容量验收通过，数据、模型、流水线哈希闭环，干净环境可复现。
绿色价值轻量模型带来低碳算力占用；提前1至3小时的预测支持"明早暂停操场活动"等可核实的预防性行动；秒级确定性清洗替代小时级人工整理。
社会影响为学校、园区、社区提供低成本、可解释的空气质量参考，辅助敏感人群场景的预防性安排（成效待真实试用验证）；材料全链路披露边界，倡导可复核的科研范式。
商业/推广潜力三形态覆盖普通用户、机构与集成方；先以长沙学校、园区试点打磨体验，再按站点契约与字段映射扩展至其他城市；开源代码与公开脱敏数据集可加速生态共建。
团队优势团队具备数据工程、时序建模、后端与全栈交付的完整能力，已独立完成从数据到产品的全链路闭环；以预注册晋级门槛、对抗性自检与诚实边界清单保障科研诚信。[待补充：成员背景与分工]

二、问题与方案

解决的问题① 站点级逐小时污染预测的时空耦合建模难；② 监测数据缺失/停报/时区错位严重；③ 常见评测存在信息泄露、分数虚高；④ 模型成果难以下沉为普通用户可用的工具
目标用户学校/园区/社区管理者（网站版）；有数据边界要求的机构（本地软件版）；集成开发者（API/SDK/CLI）
输入契约10 站 × 过去 12 小时 × 六种污染物（PM2.5、PM10、SO2、NO2、O3、CO）+ 四类气象特征
输出规模一次预测 = 120 个预测格（10 站 × 4 污染物 × T+1/T+2/T+3），逐格附风险等级
产品形态网站版（Web 工作台）· 软件版（本地工作台，同一套代码与模型包）· 开发者版（Flask API + Python SDK + CLI 共 10 条命令）
数据接入CSV/JSON 文件导入、REST 推送、HTTP 定时拉取、MQTT 回调 → 统一标准事件 → 幂等去重 → 72 小时滚动窗口

三、数据与工程

数据覆盖2022-01-01 至 2026-09-01，共 40,920 小时
数据来源全国空气质量历史镜像（污染，与官方格式重叠区校验 0 不一致单元）；NOAA NCEI Global Hourly 与 ERA5（气象）
数据哈希pollution 486efe…e3c2e；weather f5e02e…e47c（哈希不一致则禁止比较旧实验）
清洗规则UTC→北京时间统一换算（修复 +8h 错位）；非法值/哨兵值转缺失；短缺失因果前向填充 ≤3h；长缺失删窗；风向 sin/cos 圆周平均；Scaler 仅训练段拟合
时间切分train 26,926 窗（→2025-02-16）· validation 4,299 窗（→2025-08-22）· development test 8,819 窗（→2026-09-01）；三段零交集，边界删除 28 个跨界窗口
测试与验收170 项 pytest 通过；容量验收 37 项 / 0 失败；12 张浏览器截图零控制台报错；SDK wheel 隔离环境安装验证
