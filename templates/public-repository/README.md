# Public-repository release templates

This directory is a staging aid for GOV-02's separate, clean public
repository. It is not a license for this private mixed repository and must
not be copied into its history as if it were one.

When creating the public repository, copy these unmodified full legal texts to
that repository's root:

- `LICENSE`: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0.txt
- `DATA_LICENSE`: Creative Commons Attribution 4.0 International —
  https://creativecommons.org/licenses/by/4.0/legalcode.txt

Use `NOTICE` from this directory as the starting point for the public
repository's root `NOTICE`. Copy only the allowlisted assets and supporting
paths in `configs/public_release_assets.json`; its exclusions remain binding.
