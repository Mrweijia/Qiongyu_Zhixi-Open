DEVELOPER ACCESS / API & SDK

开发者入口

按现有同源 API 组织请求。生产环境请处理上传校验、异步状态和业务侧鉴权。

接口速览

POST
/api/upload 上传 pollution_file 与 weather_file
POST
/api/predict 提交 session_id 进行推理
GET
/api/health 检查服务与模型就绪状态
POST
/api/train 可选：提交训练文件、目标与时段

JavaScript 示例

                              const body = new FormData();
                                body.append('pollution_file', pollutionFile);
                                body.append('weather_file', weatherFile);

                                const upload = await fetch('/api/upload', {
                                method: 'POST', body
                                }).then(r => r.json());

                                const result = await fetch('/api/predict', {
                                method: 'POST',
                                headers: { 'Content-Type': 'application/json' },
                                body: JSON.stringify({ session_id: upload.session_id })
                                }).then(r => r.json());
